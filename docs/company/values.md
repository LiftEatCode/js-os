# Values

**Status:** Draft operating definition

Working values for JS OS design, not a ratified employee handbook:

- **State over chat.** Decisions rest on durable records.
- **Explicit tools.** No unrestricted side effects.
- **Approval for consequence.** Spend, publish, message, deploy, and refund stay gated.
- **Do not duplicate systems of record.** JS Growth owns product commercial data.
- **Increase autonomy only after proof.** Observe and recommend before execute.
