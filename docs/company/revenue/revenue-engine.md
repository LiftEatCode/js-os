# Revenue Engine v1
**Status:** Design specification

## Pipeline
**DISCOVERED → QUALIFIED → RESEARCHED → AUDITED → OUTREACH_READY → CONTACTED → FOLLOW_UP_DUE → RESPONDED → CONVERSATION → PROPOSAL → WON/LOST**

Also: DISQUALIFIED, DO_NOT_CONTACT, UNRESPONSIVE, NURTURE.

## Instrumentation
Track prospects discovered/qualified, research, audits, outreach prepared/sent, response and positive-response rates, conversations, proposals, wins/losses and reasons, new MRR, project revenue, pipeline value, stage time, acquisition cost, AI cost, and founder time.

## Attribution Goal
**Client → proposal → conversation → response → outreach → audit → prospect → source → AI/human decision**

## Safety
Quality over volume. Use legitimate channels, real evidence, respectful follow-up, opt-outs, and do-not-contact handling. No contact-form spam, CAPTCHA bypass, fabricated audit findings, or invented data.

## Optimization Questions
Which verticals, opportunity types, channels, messages, price points, and offers create profitable retained revenue?
