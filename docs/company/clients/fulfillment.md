# Client Fulfillment
**Status:** Design v1

## Cycle
**Observe → Diagnose → Prioritize → Plan → Execute → Validate → Measure → Report → Repeat**

## Prioritization
Expected business impact, confidence, effort, risk, urgency, strategic fit, dependencies, reversibility.

## Work Categories
Website/technical, SEO, local SEO, GBP, content, conversion, reputation, analytics, competitive intelligence, automation.

## Quality
Meaningful work should have a reason, expected effect, owner, validation method, history/event, and rollback path where appropriate.

## Scope
Classify new requests as included, reprioritized, separately scoped, or declined.

## Leverage
Recurring work should progressively move from founder execution to documented processes, tools, and agents where quality and safety permit.

## Communication
Report decisions, outcomes, learning, and next priorities—not busywork.
