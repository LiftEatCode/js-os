# Client Onboarding
**Status:** Draft SOP requirements

## Goal
Reach an execution-ready state quickly, safely, and with aligned expectations.

## Business Inputs
Business/brand identity, service areas, priority/high-value services, target customers, capacity, seasonality, differentiators, competitors, channels, previous marketing issues, and objectives.

## Access
As applicable: CMS/repository, hosting/deployment, domain/DNS, Analytics, Search Console, GBP, call tracking, forms/CRM, social, ads, review platforms.

Use least privilege. Never place raw credentials in prompts/docs.

## Baseline
Website state, search/index state, conversion paths, local visibility, GBP, reviews, analytics, leads where measurable, and competitors.

## First Plan
Create a 30/60/90-day plan with opportunity, evidence, expected benefit, confidence, effort, risk, dependencies, and owner.

## Done
Onboarding is complete when there is enough access, context, measurement, and agreement to execute the first priority safely.
