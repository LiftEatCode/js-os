# Website Optimization System
**Status:** Capability specification v1

## Modes
**External website:** analyze public pages and prepare recommendations; no changes without authorized access.

**Managed website:** with legitimate repository/CMS/deployment access, prepare and later execute changes under JS OS permissions, approvals, and policies.

## Loop
**Analyze → Detect → Score → Plan → Prepare → Validate → Approve when required → Deploy → Measure → Learn**

## Opportunity Types
Technical SEO, metadata, headings/content, service/local pages, internal linking, schema, broken links, crawl/indexing, mobile UX, performance, images, accessibility blockers, CTAs/forms, trust, offer clarity, conversion paths, analytics.

## Scoring
Keep impact, confidence, effort, risk, and revenue relevance separately visible.

## Autonomy
1. Analyze
2. Recommend
3. Prepare exact change
4. Branch/preview + human approval
5. Execute approved low-risk classes
6. Autonomous deployment only after evidence and policy permit

## Validation
Build/tests, type/lint checks, preview, links, metadata/schema, visual review, performance, and rollback readiness as appropriate.

## Search Quality
Content must be useful to people; do not mass-produce low-value pages to manipulate rankings.

## JS OS Boundary
Agents reason; tools act; JS OS controls permission, approval, policy, and auditability.
