# JS OS Roadmap

## Phase 0 — Foundation

Goal: establish project boundaries and development conventions.

- [x] Create repository
- [x] Bootstrap Next.js
- [x] Clean generated files from Git
- [x] Define architecture
- [x] Define roadmap
- [x] Add project validation scripts

## Phase 1 — Business State

Goal: create the durable internal model JS OS will reason about.

Planned concepts:

- Organization
- Goal
- Work Item
- Business Event
- Approval
- Agent Definition
- Agent Run

## Phase 2 — Command Center

Goal: provide a central dashboard for running JS Solutions.

Initial views:

- business overview
- current goals
- priorities
- work queue
- approval queue
- recent activity

## Phase 3 — CEO Review

Goal: produce a structured executive review from current business state.

The initial CEO capability should:

- inspect business state
- compare state against goals
- identify risks
- identify opportunities
- recommend priorities
- recommend work

It should not autonomously execute sensitive actions.

## Phase 4 — JS Growth Integration

Goal: expose real commercial data to JS OS.

Initial integration targets:

- leads
- prospects
- campaigns
- opportunities
- Website Growth Audits
- GBP Audits

## Phase 5 — Sales Operations

Goal: coordinate prospecting and sales work using existing JS Growth capabilities.

## Phase 6 — Marketing Operations

Goal: coordinate content, SEO, local SEO, social, and campaign workflows.

## Phase 7 — Client Operations

Goal: coordinate client deliverables, reporting, health, and growth opportunities.

## Phase 8 — Engineering Operations

Goal: assist with issue discovery, development work, validation, and pull-request workflows.

## Phase 9 — Higher Autonomy

Goal: selectively allow proven workflows to execute with reduced human intervention.
